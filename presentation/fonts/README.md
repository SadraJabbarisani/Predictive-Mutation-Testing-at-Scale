# فونت وزیرمتن (Vazirmatn)

ارائه با فونت **Vazirmatn** ساخته شده است. فونت داخل فایل pptx جاسازی نمی‌شود،
پس قبل از باز کردن ارائه در PowerPoint، فونت را نصب کنید:

* **ویندوز:** روی `Vazirmatn-Regular.ttf` و `Vazirmatn-Bold.ttf` راست‌کلیک کنید و Install را بزنید.
* **مک:** روی فایل‌ها دوبار کلیک کنید و Install Font را بزنید.
* **لینوکس:** فایل‌ها را در `~/.fonts` کپی کنید و `fc-cache -f` را اجرا کنید.

اگر فونت نصب نباشد، PowerPoint فونت دیگری جایگزین می‌کند و ممکن است چیدمان متن کمی به هم بخورد.
نسخه‌ی PDF ارائه (`team8_pmt_presentation.pdf`) فونت را همراه خود دارد و بدون نصب هم درست نمایش داده می‌شود.
